# 插件隐私说明

自动检测默认关闭。启用前设置页展示并要求确认数据流向。

| 接收方 | 数据 | 时机 |
|---|---|---|
| TypeSafe API | 原帖、评论、可可靠关联的上级回复正文，个人 Key | 配置个人 Key 并启用后，评论进入视野 |
| 评审 API（默认 x.aileetcode.com） | 页面快照、匿名安装凭证；投票时增加选择与序列 | 获取统计、投票、改票、撤票和离线补传 |
| 本机扩展存储 | 设置、匿名身份、缓存、待同步票；可选记住 Key | 本地运行 |

Jev 结果和个人 Key 不发送给评审 API 或 X 页面，不进入日志或发布包。Key 默认只存浏览器会话；记住后写入受限本地存储，不提供静态加密，不使用浏览器同步存储。

读取的只是当前页面 DOM，不另行抓取 X。插件跳过可识别的私密或不完整内容，但不能独立证明 X 内容真实或公开。短文与模板语言的模型判断可能错误。

服务约定：首张人工票后，该版本的文本、来源与汇总票数可以公开；单个身份的票和稳定身份标识不公开。未投票缓存以 7 天为清理阈值，实际物理删除可能等到后续访问触发。最后一票撤回立即退出公开展示。第三方复制不能召回。这些是服务端规则说明；服务端实现不在本仓库。

撤票在详情面板操作；断网时会排队。卸载会丢失身份和未同步请求，导致无法再用该身份改票或撤票。卸载前完成同步。设置页可清除个人 Key、关闭插件；关闭后暂停检测与自动同步。

一个安装身份不是一个真实人；重装和多设备可能产生多个身份。请勿把模型概率、社区比例或匿名票数当作身份认证。安全或内容下架请求可通过 SECURITY.md 所述私密渠道联系维护者。
